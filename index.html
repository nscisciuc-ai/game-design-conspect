1. Cultura Informației

Cultura informației = totalitatea cunoștințelor și deprinderilor necesare pentru a căuta, evalua, prelucra și utiliza informația eficient și etic.

📖 Informare

Identificarea surselor relevante și selecția datelor valide.

💻 Competențe digitale

Utilizarea eficientă a programelor și platformelor IT.

🧠 Gândire critică

Verificarea veridicității surselor și evitarea dezinformării.

🤝 Comunicare

Colaborare etică în medii online și proiecte de echipă.

💡 Formula Game Design-ului: Artă + Tehnologie + Psihologie + Informatică

3. Istoria Jocurilor Video

📅 Cronologie esențială pentru examen!

1958–1971 | Începuturile

1958: Tennis for Two • 1962: Spacewar! • 1971: Computer Space (primul arcade comercial).

1972–1981 | Era arcade & console

1972: Pong (Atari) + Magnavox Odyssey • 1978: Space Invaders • 1980: Pac-Man • 1981: Donkey Kong.

1983–1985 | Criza & renașterea

1983: criza industriei (supraproducție) • 1985: NES + Super Mario Bros. salvează piața.

1994–1997 | Era 3D

1994: PlayStation (CD) • 1996: Nintendo 64, Tomb Raider, Quake • 1997: Final Fantasy VII.

2004–prezent | Online, mobil & cloud

2004: World of Warcraft • 2007: iPhone & jocuri mobile • 2009: Minecraft • 2020+: VR & Cloud Gaming.

4. Tehnologii & Game Engines

Motori populari:

  • Unity – C# (2D, 3D, mobil, indie)
  • Unreal Engine – C++ & Blueprints (grafică AAA)
  • Godot – open-source, ușor și gratuit

Tehnologii emergente:

  • Ray Tracing – iluminare fotorealistă în timp real
  • Generare procedurală – lumi automate (ex. Minecraft)
  • AR/VR – imersiune (Pokémon GO, Oculus)

Exemplu de cod (Unity / C#):

Mișcarea clasică a jucătorului pe axa orizontală:

public class PlayerMovement : MonoBehaviour
{
    public float speed = 5f;  // viteza jucătorului

    void Update()
    {
        // citește inputul orizontal (-1, 0 sau 1)
        float x = Input.GetAxis("Horizontal");
        transform.Translate(new Vector2(x, 0) * speed * Time.deltaTime);
    }
}

7. Studii de Caz

🟡 Pac-Man (1980) – curba dificultății

Fiecare nivel crește viteza fantomelor treptat. Cele 4 fantome au personalități diferite (urmărire, ambuscadă), creând profunzime din reguli simple.

⚔️ Dark Souls – bucla „încearcă–eșuează–învață”

Moartea este o lecție, nu o pedeapsă. Feedback clar (checkpoint-uri, mesaje) transformă frustrarea în motivație.

⛰️ Celeste – dificultate adaptabilă

Modurile de asistență permit ajustarea dificultății fără a rupe designul. O mecanică simplă (dash) este explorată în profunzime.
